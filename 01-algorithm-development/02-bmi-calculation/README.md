# 02 - Body Mass Index (BMI) Calculation

This module calculates the Body Mass Index (BMI) based on user weight and height input, classifying the result into standard medical weight status categories using multi-branch conditional statements (`if / else-if / else`).

## 🎯 Concepts Covered
- **Input Processing:** Reading `double` values for precision.
- **Mathematical Operators:** Exponential calculations using `Math.pow()`.
- **Conditional Logic:** Multi-stage decision making with boundary checks.
