# 05 - Standard Deviation

This program calculates the population standard deviation ($\sigma$) of a 10-element dataset using a 1D double array, `Math.pow()`, and `Math.sqrt()` utilities.

Mathematical formula implemented:
$$\sigma = \sqrt{\frac{\sum_{i=1}^{N} (x_i - \mu)^2}{N}}$$

Where:
* $N$ is the dataset size ($10$).
* $x_i$ represents each individual data element.
* $\mu$ is the arithmetic mean of the dataset.
