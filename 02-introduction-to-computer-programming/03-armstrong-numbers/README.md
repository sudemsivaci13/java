# 03 - Armstrong Numbers

An Armstrong number (or narcissistic number) is a number that equals the sum of its own digits each raised to the power of the number of digits (e.g., $153 = 1^3 + 5^3 + 3^3$ or $1634 = 1^4 + 6^4 + 3^4 + 4^4$).

This program dynamically calculates the number of digits for any positive integer using digit extraction arithmetic (`%` and `/`), evaluates the sum of powers using modular methods, and lists all Armstrong numbers up to a user-defined upper limit.
